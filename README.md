# Prize Bot 🏆

A fun Telegram bot that gives virtual prize points daily with streaks, tiers, and leaderboards.

## Features
- 🏆 Daily prize claims
- 🔥 Streak multipliers
- 🏅 Tier system (Starter → Legendary)
- 🏅 Leaderboard competition
- 📊 Personal statistics

## Commands
- `/start` - Main menu
- `/prize` - Claim daily prize
- `/stats` - View your stats
- `/leaderboard` - View top users
- `/help` - Help menu

## Deployment
Deployed on Railway with GitHub integration.

## Tech Stack
- Python 3.11+
- pyTelegramBotAPI
- Railway
